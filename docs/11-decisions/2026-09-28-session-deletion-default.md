# 删除会话时默认同时删除原始记录

- 决策日期：2026-09-28
- 状态：已由用户明确确认
- 适用范围：通过 `SessionHistoryActions` 打开的会话删除确认框

## 决策依据

用户提出：“删除 sessions 的时候默认没有勾选同时删除，改成默认行为。”

代码评审随后建议恢复为默认未选中，理由是删除原始会话记录不可恢复。用户明确回复：“不恢复，这个是有意如此设计的。”

因此，默认勾选“同时删除原始会话记录”是明确要求的产品行为，应保留。

## 预期行为

- 有原始会话 ID 时，每次打开确认框，默认勾选“同时删除原始会话记录”。
- 用户可以取消勾选，仅移除 Purplemux 历史记录。
- 勾选时显示不可撤销提示，并通过“永久删除”按钮确认；打开对话框本身不执行删除。
- 没有原始会话 ID 的历史项，仅移除历史记录。
- 保留服务端对正在使用的会话的删除限制。

## 评审结论

不采纳本次评审中“将原始会话删除保持为显式选择”的恢复建议。该建议要求改变的默认值正是用户明确要求保留的行为。

删除原始记录不可恢复这一事实仍成立；本决策接受默认勾选，并保留取消勾选、风险提示和最终确认。后续评审应核对这些行为是否正确实现，不应仅因默认勾选而将其判定为非预期的数据删除缺陷。本决策不授权绕过确认框或自动批量删除会话。

## 实现位置

[SessionHistoryActions](../../src/components/features/workspace/session-history-actions.tsx) 中的 `deleteOriginal` 初始值和 `openDeleteDialog` 共同保证首次打开及再次打开时的默认行为。
