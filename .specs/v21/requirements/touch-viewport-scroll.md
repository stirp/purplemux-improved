# 触屏视口滚动约束

2026-10-13 用户反馈：iPad、iPhone 在非对话区域拖动时界面反向移动；桌面 Web 端偶尔在界面下方露出多屏灰色空白。

2026-10-15 用户补充：Chrome 中点击 Ask User Question 选项后界面瞬间跳动，再滚动滚轮出现大量灰色区域，刷新后恢复。现场 `timeline` 内层包装容器可见高度 916px、内容高度 1143px、滚动位置 226px，HTML/BODY 无溢出。

## 范围与验收

- 工作区页面在桌面 Web 及触屏设备均不得发生文档级滚动或在应用外壳下方露出灰色空白；触屏空白区拖动不移动整个应用。
- 对话、侧栏及弹层内部可滚动内容继续按正常方向滚动。
- 键盘弹出、关闭及视口变化后，应用仍适配可见区域；桌面鼠标环境保持原行为。
- 非工作区页面不受根层滚动限制影响。
- Firefox 111 及之后的受支持浏览器应应用相同的滚动约束；页面切换时清理作用域标记。
- 长对话中点击问题选项、键盘切换选项及继续追加 AI 内容时，消息列表内部正常滚动，输入框和状态栏不随外层 Panel 滚走，不露出底层灰色区域。
