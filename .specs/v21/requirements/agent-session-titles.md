# Agent 会话标题同步

2026-10-14：Claude 和 Codex 的 Tab 标题随当前会话标题更新；Sessions 工作状态列表展示同一标题。

- 会话详情已有的标题计算结果是展示依据，包括自定义标题、摘要及首条用户消息的现有优先级。
- 有明确手动重命名的 Tab 保留用户命名；没有会话标题时沿用现有进程标题及消息回退。
- 会话切换期间不能显示上一会话的缓存标题；不改变终端或其他面板的标题。
- Sessions 中活动会话优先展示当前会话标题，历史条目仍展示已有提示词。
- 手动重命名 Claude/Codex Tab 时，将名称保存为该会话在本应用中的标题；切换和重开仍显示新标题。尚未取得会话 ID 时先绑定 Tab 身份，取得 ID 后迁移标题。清空名称移除覆盖值；非 Agent Tab 仍仅重命名 Tab。
- 不修改 Claude/Codex 的原生会话文件；保存失败提示错误且不修改 Tab 原名称。删除会话时清理其标题记录。

## 验收

1. Claude/Codex 会话标题变化后，Tab 与 Sessions 活动项同步显示。
2. 手动命名与非 Agent Tab 不受影响；会话切换不泄露旧标题。
3. 类型检查、相关测试、改动文件 ESLint 通过；浏览器未执行须记录。
4. 手动命名持久化到 Sessions 和 Tab，重开及同一会话的其他 Tab 可见，失败不留下单侧标题。
5. 曾绑定旧会话的 Tab 在尚无新 ID 时重命名，取得新 ID 后标题只归属新会话；其他 Tab 的会话覆盖标题不遮盖旧布局中已有的手动 Tab 名称。
6. 会话身份先于摘要/消息更新时，不显示旧会话的回退标题；Agent Tab 既有布局名的重命名在一次配置写入中完成，失败不产生 Tab 与 Sessions 标题分歧。
