# Sessions 查询

2026-10-15：用户反馈 Sessions 管理混乱，希望在截图中的 Sessions 页面支持查询。

- 页面顶部提供即时关键词搜索与清空按钮，桌面侧栏和移动导航共用。
- 查询本页面已有的活动会话、持久会话索引及保留的历史摘要；支持标题、工作区名称/路径、原生会话 ID、用户提示词和结果摘要，不扫描原始对话全文。
- 去除关键词首尾空白，按不区分大小写的连续文本匹配；空白输入等同未搜索。
- 保持原有工作状态分组，数量按匹配会话去重计算。搜索期间临时展开匹配分组和命中的较早记录，清空恢复原折叠偏好及历史展开状态。
- 显示匹配会话数，无匹配时显示明确提示且可清空；清空按钮与 Escape 可恢复完整列表。
- 搜索只影响当前面板，不保存、不发查询请求、不更改工作区状态汇总；实时同步后按当前关键词重新计算。
- 搜索结果继续使用既有导航、状态编辑与删除入口。

验收条件见[功能规格](../features/session-search/spec.md)。

## 项目名称必显（2026-10-15 补充）

用户追问部分 session 只有标题，并明确每个 session 必须显示项目名称。活动会话、普通历史、无轮次索引和更早记录均需显示独立项目名称行，不以会话标题替代；长名称允许换行。空白历史名称需回退到当前工作区或其他已有名称，无法取得名称时用目录末段、工作区 ID 或“未知项目”兜底，不猜测项目归属。
