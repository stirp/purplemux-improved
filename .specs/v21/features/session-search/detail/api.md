# Sessions 查询数据约定

- 复用 `collectWorkSessions` 已去重并排除删除标记的数据，以及现有 Tab、Workspace、sessionWorkflow 和历史 Store。
- 标题复用 `agentSessionTitle`，历史覆盖标题来自 `sessionWorkflow.titles`；当前工作区名称及历史导航名称/目录均可匹配。
- 查询字段为标题、工作区名称/路径、原生 session ID、live.lastUserMessage、entry.prompt/result 和 olderEntries.prompt/result。摘要先经 `stripMarkdown` 转为界面文本；不搜索内部 Tab key 或删除标记。
- 命中较早记录时仍返回所属会话，并仅附带匹配的较早轮次；保持输入数据不变及原会话顺序。
- PR #39 Review 修正：较早轮次的匹配字段包含所属会话解析后的项目名称，与该行实际展示一致；当前项目名称命中时保留全部较早轮次，历史保存的旧名称仍可查询。此继承仅适用于展示的项目名称，不把父会话标题的命中扩展到所有较早轮次。
- 数据边界为当前已同步的会话索引和仍保留的轮次摘要，不能查找已裁剪轮次或未载入的原始对话全文。
- 不新增 HTTP 接口、配置字段、持久化或数据迁移；搜索状态仅保存在当前组件。
- 项目名解析统一忽略空白字符串；优先当前 Workspace.name，再取最近历史、导航索引、活动信息和较早轮次中的非空名称。等于 workspaceId 的占位名称留到最终 ID 回退；名称均缺失时按当前目录、最近历史、导航索引、活动信息和较早轮次的目录末段回退，兼容正反斜杠与末尾斜杠。完全缺失时显示本地化“未知项目”。渲染与搜索使用同一解析值，不改历史磁盘数据或导航目标。
