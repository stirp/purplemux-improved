# Sessions 查询界面

- `NotificationPanel` 顶部采用现有 Input、Search 图标和带无障碍名称的清空按钮，提示“搜索会话…”，说明范围为标题、工作区、会话 ID 和历史摘要。
- 输入框不随列表滚动，窄屏允许说明换行。输入时更新匹配会话数，使用 polite 状态区域宣告结果。
- 搜索期间分组标题显示匹配数量并禁用折叠；命中的较早记录自动展开，显示 prompt 和 result，隐藏无关轮次。
- 空关键词沿用既有空列表文案；有效关键词无结果时提示“没有匹配的会话”，保留搜索框和清空入口。
- 桌面 Sidebar、移动 MobileNavigationSheet 和 NotificationSheet 复用同一组件；不自动聚焦以免移动键盘意外弹出。
- 所有会话行及更早记录复用项目名称展示：Provider 图标和项目名独占一行，标题与时间分行显示。项目名允许长文本换行并提供完整 title，不能只剩图标或空白；更早记录使用所属会话的统一项目名称。
