# 界面

桌面根工作区右键菜单和移动根工作区设置菜单在有直接子工作区时显示“Worktree 关系与同步”。弹窗展示所有后代的父到子关系、双向提交数、合并操作及确认。子工作区行额外显示父名称；无子节点时关系视图隐藏，管理入口仍显示。

关系视图独立展示加载错误与上一次合并错误；自动或手动刷新不会清除合并失败原因和主工作树终端恢复提示。下一次确认执行合并时清除旧操作错误。

PR #37：共享发布表单允许 Git 主工作树在满足其余条件时推送和创建 PR/MR 草稿；仅 main 标记不能禁用按钮。提交发布快捷入口及 Worktree 管理交付入口使用相同规则。

2026-10-14 整合：有子节点的项目根节点只显示一个统一管理入口；弹窗上方可切换“关系与同步”与“管理 Worktrees”。仓库视图复用原有管理列表、筛选、容量测量、接管、打开、交付、删除和批量清理交互；切换保留表单选择状态。无子节点的根及非根工作区使用统一弹窗的仓库视图。

2026-10-14 交付入口：所有工作区菜单统一显示“Worktree 管理”；无子工作区时隐藏关系 tab、直接显示仓库视图。桌面与移动工作区行不再显示单独的 PR/MR 图标。仓库视图每条 worktree 仍保留“同步与交付”操作。AI 生成提交信息弹窗提交成功后，在提交结果下方直接显示该工作树的推送及 PR/MR 草稿表单。

变更面板快捷入口：DiffPanel 顶部在 Changes、History 均显示“提交与发布”文字按钮，桌面与移动共用；窄屏工具栏允许换行。按钮打开共享 GitCommitDialog，支持 AI 或手写提交信息、提交及随后发布。没有待提交改动时展示提示并直接进入已有提交的发布表单；表单显示目录、分支和短 HEAD。非 Git 目录、detached HEAD、加载或同步中禁用入口。
