# 工作区菜单顺序统一

- 来源：用户于 2026-09-28 提出的需求。
- 原始要求：移动端 workspace 菜单顺序和 Web 不同，两端均调整为“创建 Git 子任务、管理 Worktree、移动分组、重命名”，并按照 spec 完成实现。
- 确认依据：用户已明确指定四项顺序并授权实现，无待确认的产品选项。
- 范围：桌面工作区菜单与移动导航中的工作区菜单。删除操作保留在末尾并与普通操作分隔。
- 现状：桌面为管理、创建、重命名、移动分组；移动端为编辑工作区、创建、管理、删除，编辑弹窗合并了名称和分组。
- 实现约束：移动端拆为独立的移动分组和重命名入口，复用编辑弹窗及已有词条；子工作区不可独立移动分组；不变更后端契约。
