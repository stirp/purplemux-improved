# 用户流程

1. 通过桌面右键/设置按钮或移动端设置按钮打开工作区菜单。
2. 按创建、管理、移动分组、重命名顺序选择操作。
3. 移动端选择操作时关闭菜单，再打开相应弹窗。创建和管理沿用原回调。
4. 移动分组只修改 groupId，重命名只修改 name。未修改时保存禁用。
5. 保存成功关闭弹窗，失败保留当前输入，沿用 store 的回滚/错误提示。
6. 删除继续走原确认流程；子工作区不允许独立移动分组。

## 边界

- 没有分组：分组弹窗仅显示未分组，无改动时保存禁用。
- 当前已在目标分组：桌面该选项继续禁用；移动端保存禁用。
- 子工作区：分组入口可见但禁用，其余操作不受影响。
- 页头完整编辑继续支持同时修改名称和分组。
- 单纯打开菜单不调用新接口，不增加等待过程；取消弹窗不保存。
