# 界面规格

## 菜单顺序

| 顺序 | 操作 | 桌面 | 移动端 |
| --- | --- | --- | --- |
| 1 | 创建 Git 子任务 | 原创建回调 | 原创建弹窗 |
| 2 | 管理 Worktree | 原管理回调 | 原管理弹窗 |
| 3 | 移动分组 | 保留分组子菜单 | 编辑弹窗的 group 模式 |
| 4 | 重命名 | 原行内编辑 | 编辑弹窗的 rename 模式 |
| 分隔 | 分隔线 | 原菜单分隔线 | 语义分隔线 |
| 5 | 删除/移除工作区 | 原危险操作 | 原确认弹窗 |

移动端复用 sidebar.moveToGroup 和 terminal.rename 文案。子工作区分组入口禁用，并具有禁用视觉反馈。沿用 min-h-11 触摸高度及原生按钮键盘操作。

## 编辑弹窗

- 默认 edit 模式保持名称与分组组合编辑，兼容页头调用。
- rename 模式标题为重命名，只呈现名称输入；空白或未改变名称无法保存。
- group 模式标题为移动分组，只呈现分组选择；保留未分组选项，即使没有可用分组也能显示当前状态，无改动时禁用保存。
- 使用原 Dialog/Select 焦点管理和转场。保存期间展示原 Spinner 并禁用重复提交，成功关闭，失败保留表单与既有 store 错误提示。
- 菜单本身没有加载请求；无需引入加载、缓存或空态骨架。
