# 工作区菜单顺序统一

## 概述

依据 [原始需求](../../requirements/workspace-menu-order.md)，统一桌面和移动端工作区菜单。需求顺序及实现授权已由用户明确确认。

## 功能与验收标准

- AC1：两端一级菜单依次为创建 Git 子任务、管理 Worktree、移动分组、重命名；文案复用当前语言词条。
- AC2：删除操作保留于末尾，前置分隔线，保持原有危险操作样式及确认流程。
- AC3：移动端移动分组和重命名使用独立入口，选择后关闭菜单并打开对应弹窗；一个操作只提交对应字段。
- AC4：子工作区的移动分组入口显示但禁用；分组提交逻辑仍保护子工作区。
- AC5：保留桌面分组子菜单、新建/移出分组、行内重命名及工作树入口的原有回调；页头的完整编辑弹窗保持兼容。
- AC6：分组选择支持已有分组与未分组；无改动及保存中禁止重复保存，失败保留弹窗；移动菜单保持至少 44px 触摸区域。
- AC7：菜单排序不新增请求、路由、依赖或数据存储；保留已有弹层焦点管理及样式。
