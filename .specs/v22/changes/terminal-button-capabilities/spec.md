# 终端按键栏与自定义命令能力增强

## 原始需求

1. 快捷键栏支持自定义顺序及哪些显示、哪些隐藏。
2. 增加 F1–F12 按钮。
3. Terminal 自定义按钮编辑时可选择是否自动输入回车。

## 行为与覆盖关系

- 替代固定虚拟按键栏不可配置的行为；桌面、移动端及使用同一按键栏的 Agent 终端共享配置。保留整栏 auto/always/never 的既有显示策略。
- 按键栏提供固定的设置入口。设置弹窗列出所有按键，以勾选控制显示，以上移/下移调整顺序，支持鼠标、触摸和键盘操作。隐藏条目保留排序位置，允许全部隐藏，此时设置入口仍可用。取消不保存，保存成功后才更新按键栏，失败保留草稿并提示；加载失败支持重试且不允许覆盖未知配置。
- 原有 11 个按键默认保持顺序，F1–F12 默认追加显示；按键栏可横向滚动，设置入口保持可见。设置弹窗适配窄屏及纵向滚动。
- F1–F4 发送 xterm 的 SS3 序列 OP/OQ/OR/OS，F5–F12 发送 CSI 15~/17~/18~/19~/20~/21~/23~/24~；不会触发浏览器功能键动作。原有 Ctrl/Shift 行为保持；隐藏处于激活状态的修饰键时清除该状态。
- 配置以稳定按键 ID 和 visible 布尔值组成的有序数组保存到实例共享 `~/.purplemux/workspaces.json` 可选字段 `terminalKeys`。缺失时使用默认值；读取时补齐未来新增按键、忽略未知/重复 ID；API 拒绝未知、重复、缺项、非布尔值或非法结构。复用文件锁、原子写入、广播、SWR 聚焦与重连刷新。并发设置以最后成功保存为准，保留其他工作区数据及命令。
- 增加 `GET/PUT /api/terminal-keys`，PUT 请求 `{ keys: [{ id, visible }] }`，返回保存后的完整数组；非法参数 400，失败 500，其他方法 405。客户端不提供任意转义序列配置。
- 替代自定义命令“一律补回车”的条款：命令增加可选 `autoEnter` 布尔值，新增和旧配置默认开启；编辑可开关并持久化，非法类型由 API 拒绝。兼容旧客户端编辑时省略该字段，保留已保存值。
- 关闭自动回车仅不额外追加末尾 CR；保留用户命令已有换行并沿用 CRLF/LF 到 CR 的归一化。因此多行或自带末尾换行仍会产生回车，编辑界面说明此边界。开启时沿用原来的末尾补一个 CR 行为。
- 自定义命令的排序、删除确认、输入校验、断线禁用、不补发、copy-mode 退出及发送目标保持基线约定。保存和排序不得发送终端输入。

## 验收标准

1. 旧配置显示原按键和 F1–F12；设置顺序和显示后保存、刷新以及跨客户端刷新均一致；全部隐藏仍可打开设置恢复。
2. 每个功能键发送正确字节，常规按键及修饰键行为保持；隐藏激活的 Ctrl/Shift 后状态清除。
3. 设置可取消；加载失败可重试；保存失败保留草稿，保存中阻止重复操作及关闭；窄屏无页面横向溢出。
4. 按键 API 校验及磁盘失败不覆盖数据、不广播；与命令及工作区字段并发保存互不丢失。
5. 新旧命令默认回车，编辑关闭后发送单行命令不追加 CR；刷新后仍关闭；开启、多行、已有末尾换行及旧客户端兼容符合约定。
6. 运行相关自动化测试、完整 TypeScript、改动文件 ESLint，并进行构建或浏览器验证；如实记录限制。
