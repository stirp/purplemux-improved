# AI 代码块复制按钮

## 用户原始需求

在 AI 给出代码块的时候，应该在代码块的右上角显示复制按钮。

## 范围与行为

- 在现有 AI 回复及 AI 计划详情的 Markdown 代码块右上角增加常显复制按钮，桌面与移动端均可操作。
- 对会话面板基线仅新增代码块复制交互；保留 Markdown、语法高亮、文件链接及区域字体行为。
- 带语言、无语言、缩进代码块均支持；行内代码不增加按钮，工具输出、diff 和终端不在范围内。
- 复制当前代码块的纯文本，保留缩进、空行及 Markdown 渲染后的末尾换行；不含围栏、语言标签、按钮文本或高亮标签。
- 按钮独立于横向滚动区域，顶部预留操作行，避免遮挡代码；使用现有主题与按钮组件，不新增依赖。
- 复用现有剪贴板工具，支持安全上下文及普通 HTTP 回退。成功显示“已复制”并在两秒后恢复；失败显示错误通知且允许重试。
- 按钮具备本地化名称、键盘焦点与原生按钮操作语义；各代码块独立反馈，不写配置。

## 验收标准

| 编号 | 条件 | 验证方式 |
| --- | --- | --- |
| CB-01 | AI 回复与计划详情每个块级代码有右上角常显按钮，行内代码无按钮 | 组件测试与浏览器检查 |
| CB-02 | 仅复制目标块纯文本，保留空白、特殊字符及换行，高亮正常 | 组件测试 |
| CB-03 | 成功反馈独立、两秒后恢复，失败可重试 | 组件测试 |
| CB-04 | 更新消息后复制当前内容；HTTPS 和 HTTP 回退可用 | 组件测试 |
| CB-05 | 窄屏、长行、深浅主题下按钮可见且不遮挡代码，键盘可操作 | 浏览器检查 |
| CB-06 | 相关测试、完整 TypeScript 与改动文件 ESLint 通过 | 命令验证 |
