# 紧凑工作区侧栏

## 用户原始需求

用户指出工作区树状列表不够美观，要求现代设计方案及图片预览；查看浅色、深色紧凑项目树预览后确认：“好，就这样修改试一试”。

## 范围与覆盖关系

- 优化桌面工作区侧栏，浅色与深色沿用当前主题，使用低饱和紫色选中背景和左侧标记。
- 替代 v21 工作区行的常驻目录、分支及多行状态展示：默认单行，完整名称、目录、分支和端口在悬停提示及无障碍描述中保留。
- 替代 v21 桌面根管理按钮始终显示的约定：根管理按钮与设置按钮在 hover、focus-within、菜单打开时显示；触摸设备保留管理按钮和长按菜单。
- 工作阶段沿用 session-task-status 的规则和原文案；“审批中”不重命名为“待确认”。Agent 等待输入以独立状态展示，未开始不占位，已完成以小图标显示。
- 保留现有区域字体覆盖；默认采用 UI 字体，但不清空用户设置。不改变主题默认值、侧栏宽度持久化或全局配色。
- 预览右侧聊天内容只是上下文示意，本需求不改造聊天区域，不增加快捷键、置顶、最近访问等功能。

## 功能与边界

1. 工作区名、目录/分支图标、子项数量、紧凑状态同排展示；默认行高约 36px，大字号可自然撑高，触摸行最小 44px。
2. 分组名称弱化，计数右对齐，组间留白；树的 16px 缩进、六层视觉上限、孤立和循环节点的可访问性沿用基线。
3. 增加工作区搜索，按名称、目录、worktree 分支忽略大小写匹配。结果保留匹配节点的祖先并临时展开所在分组；不修改存储的折叠状态。
4. 搜索中禁用工作区和分组拖拽，避免过滤结果产生误排序；清空或 Escape 恢复原始树和拖拽。提供无结果提示。禁用拖拽不禁用触摸长按菜单：搜索结果静止长按仍打开菜单，移动手指取消长按并允许滚动，不触发拖拽事件。
5. 桌面仅使用紧凑状态表现，共享组件的移动导航默认表现保持兼容。状态数据与去重、人工优先规则复用原实现；连接中断时不伪装成正在运行。
6. 保留点击选择、双击重命名、键盘选择/菜单、右键、长按和管理按钮的事件隔离，以及删除确认、失败提示、WebSocket 重连。
7. 搜索文案遵循现有国际化体系；无后端接口、数据格式、依赖或配置迁移。
