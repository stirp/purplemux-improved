# 界面约定

- 使用现有 sidebar、muted、ui-purple、ui-amber、ui-blue、ui-green 主题变量，不增加渐变、阴影或大面积高饱和颜色。
- 侧栏顶部保留品牌和退出；工作区/会话标签使用本地化文案。工作区标签下方增加带搜索图标与清空按钮的输入框，不展示未实现的快捷键。
- 节点使用细边框和小圆角包围完整行，选中时显示浅紫背景与独立左侧标记。名称为主要信息，非选中节点保持清晰的前景色。
- 路径、分支及端口收纳至名称悬停提示，工作区行提供同样的无障碍描述。子项使用分支图标和低对比连接线，不额外重复名称或分支行。
- 状态独立于操作区；宽侧栏显示图标及短文字，窄侧栏只保留带语义标签的图标，完整状态通过提示读取。悬停、键盘聚焦和菜单打开时均不隐藏状态图标及其 title/aria-label。工作阶段审批中与 Agent 等待输入分别保留其语义。
- 搜索结果禁用拖拽但保留静止长按菜单；长按前移动允许原生滚动，菜单打开后的释放点击不穿透，首次菜单操作可立即执行。
- 根管理按钮及菜单按钮只在桌面悬停、聚焦和菜单打开时出现；窄侧栏优先保留名称和菜单，管理操作仍可经菜单进入。触摸设备保留长按菜单与管理入口。
- 移动导航使用原布局，不把桌面紧凑模式默认应用到共享状态组件的其他调用点。
- 区域字体覆盖继续高于默认字体，行高由文字自然撑开；状态文本在窄侧栏退化为图标以减少挤压。
