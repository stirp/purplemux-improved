# 会话自定义标签

## 原始需求

用户希望周报助手等会话能够长期存在、周期性唤起，并指出这种属性与进行中、审批中可以共存。在讨论独立标签方案后，用户要求：“那自定义标签的使用方式，我需让你设计一下界面。”

## 范围与覆盖关系

2026-10-17 已交付界面提案与独立原型；2026-10-18 用户确认：“好，就按照这个先开发吧”。本轮将已确认的标签设计接入应用的 Sessions 共用面板、服务端存储与同步机制。历史原型及其验证记录保留，不能作为本轮应用验证证据。

沿用工作状态基线的四种阶段、人工状态优先及工作区汇总语义；沿用查询基线的会话去重、搜索与折叠恢复；沿用项目层级增量中的根项目、当前项目、会话标题结构。新增独立标签筛选和标签维护的界面约定，不用标签替换工作状态。

本次不实现收藏、自动调度、开始新一轮、会话保留策略或后台进程常驻。“常驻助手”是用户可自定义的标签示例，不附带运行或保留行为。

## 设计约定

1. 一个会话可有多个标签，标签不随工作状态变化。标签目录供当前应用的会话共用，不创建额外的项目层级。
2. 搜索框下放置“全部”、两个标签快捷项和“标签”入口。入口支持搜索和多选，并明确“同时包含所选标签”；多标签采用 AND，与关键词也是 AND。卡片标签点击切换为该标签的单选筛选，避免意外叠加；其他已选标签在条件条中明确展示，可单独移除。
3. 筛选结果仍按未开始、进行中、审批中、已完成分组，计数按会话去重。筛选期间临时展开命中分组，清空条件恢复用户原折叠状态。标签筛选不改变原关键词匹配范围，标签名称通过标签面板搜索。
4. 会话卡片保留项目路径、主标题、摘要、状态编辑和历史入口。标签独立一行，最多显示两个，超出显示“+N”；“+N”和标签编辑按钮均打开该会话的标签编辑器。无标签时显示“添加标签”。编辑操作不触发会话导航。
5. 会话编辑器支持搜索、勾选、取消勾选以及输入新名称后创建；按“保存”统一提交，取消不修改。新标签也随保存一起创建。名称去除首尾空白，1–24 个 Unicode 字符，同名忽略大小写，不允许重复创建。标签管理支持新建、重命名、有限色板和删除确认；删除只解除标签关联，不删除会话。
6. 桌面筛选采用锚定面板，编辑和管理采用对话框；移动端统一采用底部面板，固定标题和底部操作区，列表内部滚动。关闭、Escape 或遮罩取消草稿，返回触发按钮；弹层有焦点约束。
7. 标签使用低饱和紫、珊瑚、粉、灰色，状态继续使用原有状态色；颜色仅辅助区分，名称始终可读。覆盖浅深色、320/390/430px 及桌面窄侧栏；移动触控区域至少 44px。
8. 空目录引导创建标签；空结果保留筛选并提供清除入口。保存中禁止重复提交及关闭；失败保留草稿可重试。旧数据默认无标签，刷新、重连及多客户端复用 workspace 同步。演示开关仅保留于独立原型。
9. 标签目录和关联存入 workspaces.json 的 sessionWorkflow；身份沿用 provider + session ID / history ID / Tab ID。首次绑定迁移并消费临时关联，Tab 复用不得继承旧会话标签；删除会话清理关联但保留标签目录。无标签行为沿用基线。
10. 更新在 workspace 全局锁内原子执行，目录创建和关联保存同成同败；以标签修订号检测并发，冲突提示重新打开编辑器，保留草稿但不自动覆盖他人的修改。删除或隐藏的会话不能被迟到写入复活。
11. 标签目录初始为空，不内置“常驻助手”；筛选默认全部，仅在当前面板生命周期保留。远端删除标签后自动移除无效筛选，远端重命名后即时更新。正式范围为桌面/移动 Sessions 及通知抽屉共用面板，不新增对话内容区或原生终端标签栏。

## 验收标准

- 应用能够实际操作筛选、搜索、标签编辑、创建、重命名、颜色修改、删除确认和清空；取消编辑不产生目录或关联变更。
- 同一个“常驻助手”标签同时出现在进行中、审批中和已完成的会话中。
- 标签操作与会话导航、工作状态彼此独立；多标签筛选含义可见，无结果可恢复。
- 浏览器检查桌面、移动、浅深色和弹层布局，记录交互检查结果及真实应用验证限制。
- 验证持久化、旧配置、首次绑定及复用、删除清理、失败与并发冲突、重连同步；相关自动化测试、完整 TypeScript、改动文件 ESLint 和浏览器检查通过，未覆盖事项如实记录。
- 本需求文档的路径、引用和差异格式有效，不修改版本级汇总。

## Review 修正（2026-10-18）

Tab 复用后无原生 ID 的新会话添加标签，再绑定原生会话 B 时，必须消费临时会话索引，不受该 Tab 曾绑定 A 的记录影响。绑定前已清空标签或目标 B 已隐藏时，也须清理临时索引；绑定后及关闭 Tab 后，列表和工作区状态汇总仅包含实际会话，不能残留无导航身份的空会话。原生会话 A 的标签及状态不变，人工 fallback 状态仍只在首次绑定时迁移。
