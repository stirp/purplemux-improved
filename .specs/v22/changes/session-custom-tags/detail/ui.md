# 会话标签界面

## 列表与筛选

现有侧栏宽度内增加标签工具条，不新建导航树。默认“全部”；设计稿初始选择“常驻助手”，突出同一标签下不同工作状态可共存。两个快捷标签按目录顺序展示；本轮不设计置顶或拖拽排序。

搜索 → 标签快捷项及入口 → 已选条件（多选时显示“同时包含”）→ 会话总数 → 原状态分组。标签选择器含搜索、复选列表、清空、管理标签入口；选择立即筛选，关闭保留已选条件。“全部”仅清空标签，保留关键词；“清除全部筛选”同时清空关键词和标签。

卡片的信息顺序：根项目 › 项目、会话标题及 Provider、摘要和时间、标签行、工作状态与历史入口。卡片的标签是筛选快捷键；独立编辑图标和“+N”是编辑入口。编辑图标始终可见，不依赖悬停。长名称换行，标签超过两项收纳但可通过编辑器查看完整列表。

## 编辑会话标签

标题“编辑标签”，副标题显示会话名称。标签搜索只过滤选项，不清除已选项。复选项显示标签名及选中状态，底部显示已选数量、“取消”和“保存”。没有同名标签时显示“创建「名称」”；创建加入本次草稿，保存前不进入共享目录，取消一起丢弃。

保存中禁用重复提交和关闭；成功后同步卡片及当前筛选结果。如果移除标签导致会话离开结果集，用成功提示说明“标签已保存，该会话不再匹配当前筛选”。失败保留编辑器和草稿，显示行内错误及“重试保存”。

## 管理标签

入口位于标签筛选器底部。列表展示名称、颜色和关联会话数，每项提供“编辑”和“删除”；顶端支持搜索及新建。编辑表单使用名称和四种低饱和色板。名称校验在原位提示，不能仅依赖颜色表达错误或选中。

删除确认文案：“删除「周报」标签？将从 2 个会话中移除此标签，会话和工作状态会保留。”按钮为“取消”和“删除标签”。成功后同步目录、卡片和筛选条件；删除当前筛选项时同时移除此条件并提示。

## 响应式与键盘

桌面侧栏 352px；内容区仅辅助展示标签操作不打断当前对话。320px 时工具条快捷项可横向滚动，“标签”入口始终可见；已选条件及长标签换行，页面本身不横向滚动。

移动端筛选、编辑和管理打开底部面板，最大高度受可视区域约束；固定标题与底栏，内容可滚动。所有操作触控高度至少 44px，选择框与整行标签关联。原型使用浏览器原生 dialog；正式应用使用现有 shadcn/Base UI Dialog 提供焦点约束，Escape 取消草稿并返回原入口。

## 原型边界

使用独立 HTML/CSS/JavaScript，适配离线直接打开；无第三方网络资源，无生产请求。设计预览工具条提供桌面/手机、浅深色、一次保存失败和重置示例。预览控制与应用界面分开。

应用正式实现复用 shadcn/ui 的 Button、Input、Popover、Dialog 及现有主题变量，移动端将 Dialog 显示为底部面板；本原型不需要 Next.js 运行环境。示例对话、历史和工作状态切换仅用于查看标签共存效果，不调用真实 Agent。
