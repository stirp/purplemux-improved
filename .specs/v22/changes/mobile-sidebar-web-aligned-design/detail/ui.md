# 界面与操作细节

## 视觉层级

从上至下为品牌与关闭、工作区/会话切换、搜索、项目树、底部新建及工具。列表是主要内容，路径和分支不在每行重复。名称使用约 14px，辅助说明约 12px；低饱和状态与名称分开，选中用背景和左侧细线双重表达。

390px 手机抽屉宽 366px，保留 24px 遮罩作为返回上下文。320px 手机宽 296px。项目行至少 48px；“更多”44×44px、页签44px、搜索44px。预览中的图形是本地 SVG 线性图标，应用实施使用既有 lucide-react 与提供方图标。

## 操作面板

每行常显省略号；底部面板包含完整项目名、目录、分支、端口及完整状态，下方提供创建 Worktree、管理 Worktree、移组、重命名和删除。移组限制继承现有规则。完整文本可换行和选择复制；删除隔开并用危险色，实际执行仍需要原确认流程。

面板限制最大高度并内部滚动；支持关闭按钮、遮罩、返回键或 Escape。应用实施需管理焦点并返回触发器，避免双层弹窗抢焦点。预览用原生 dialog 模拟，菜单操作仅提示演示，不调用接口。

## 渐进披露

工作区默认只展示名称、数量和必要状态。展开显示其 Tab，当前 Tab 允许一行摘要。完整信息在更多面板可读，不能依赖 title 或悬停。状态图标保留无障碍名称；搜索结果不得伪造匹配摘要或改变真实归属。

## 预览范围

预览支持浅深色并列查看、项目搜索、工作区展开/收起、Tab 选择和操作面板。会话标签、创建及工具为演示反馈，不代表对应应用功能已实现。样例目录为虚构路径；图中操作面板示例为普通根工作区。

## 审查修正：原生复制菜单

详情通过 Portal 渲染，React 事件仍会沿组件树冒泡。行级 contextmenu 和键盘菜单处理仅接受工作区行的实际 DOM 后代事件；面板元数据的原生菜单与文字选择不被取消。行级右键、菜单键和静止长按沿用原行为。
