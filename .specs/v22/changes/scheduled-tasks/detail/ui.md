# 界面和使用流程

1. 桌面点击工作区行的设置按钮或右键菜单，选择「定时任务」。移动端打开工作区列表，点击工作区旁的设置按钮，选择「定时任务」。
2. 点击「新增任务」，选择 Shell、Claude Code 或 Codex，填写名称、工作目录和命令/提示词。
3. 选择单次、每天或每周；周期任务填写 IANA 时区，单次时间使用浏览器时区并提交明确 UTC 时间。可调整超时，默认启用。
4. 保存后展示任务类型、启停状态、计划、下次时间、目录及操作。新增/编辑表单可纵向滚动，窄屏需滚动到保存按钮。
5. 「立即执行」在独立后台进程启动任务。展开「最近执行记录」查看状态、时间、退出码和文本输出。任务完成前不展示实时输出流。
6. 暂停只取消未来触发；运行中禁止再次手动执行、编辑和删除。删除需第二次点击确认；取消不修改配置。

读取失败显示重试；保存失败显示错误并保留草稿。每 4 秒刷新任务及记录，聚焦和网络重连刷新；读取、刷新不会触发任务。

简体中文和英文提供完整文案，其他现有语言目录提供英文回退文案。复用现有 Dialog、Button、Input、Textarea、react-hook-form、Zod 和 SWR。
