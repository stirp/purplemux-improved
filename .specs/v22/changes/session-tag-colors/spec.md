# 扩展会话标签颜色

## 原始需求

用户提供编辑标签信息截图，指出：“标签颜色还是只有几个啊”。

## 范围与覆盖关系

替代会话自定义标签基线第 7 条及接口详情中的四色限制，以及标签浏览增量中“色板不变”的边界。本次将固定色板扩展为九种，复用项目已有低饱和主题色：紫、珊瑚、粉、灰、蓝、青绿、琥珀、绿、红。颜色只辅助分类，不改变工作状态语义；不引入自定义 HEX、排序或新存储字段。

## 行为与验收

1. 新建、编辑表单提供九种有名称的颜色选项，名称及单选选中状态不依赖颜色表达；窄屏换行，移动触控高度至少 44px，低高度下列表可滚动且保存、取消可达。
2. 新增颜色可通过创建、编辑及会话分配请求保存，服务端和表单使用同一颜色枚举；未支持的颜色仍拒绝。默认紫色、原四种枚举值与旧数据兼容。
3. 管理列表、选择器和会话卡片使用一致色值，并适配浅色和深色；颜色修改不改变标签 ID、会话关联或工作状态。保存失败与并发冲突沿用现有行为。
4. 新色名称覆盖所有现有 locale；简繁中文完整本地化，其他语言沿用现有标签文案的英文策略。
5. 自动化验证新增颜色请求与持久化往返、旧色兼容，以及实际表单选择新色保存后重新打开仍选中；执行相关测试、完整 TypeScript、改动文件 ESLint，并浏览器检查九色在桌面、320px 和低高度下的可达性。

见 [任务](./task.md) 和 [实施与验证](./result.md)。
