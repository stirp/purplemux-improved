# Sessions 项目层级与卡片布局

## 原始需求

“这个界面不是很合理，一方面需要你改造设计；另一方面我需要能显示三类信息：根项目名称，项目名称，tab 标题。”用户提供移动端 Sessions 截图。

## 范围与覆盖关系

替代 Sessions 查询基线中 Provider 与单一项目名独占一行、活动/历史采用不同信息顺序的布局。桌面侧栏、移动侧栏及通知抽屉共用卡片；工作区导航自身不变。保留状态分组、人工状态保存、会话身份导航、删除确认及搜索折叠恢复语义。

## 行为与验收

1. 活动、历史、无轮次索引和较早记录均展示“根项目 › 项目”及独立主标题。根与当前项目即使同名也保留两级，以免两个不同项目同名时丢失语义。完整名称和标题可换行，不能只依赖悬停读取。
2. 根项目按 `parentWorkspaceId` 追溯到无父项目的祖先，支持多层；名称复用项目名称的空白过滤和目录末段/ID 回退。父项缺失、循环或项目已删除而无法确定根时显示本地化“未知根项目”，不从目录或分组推断归属。当前项目继续沿用原历史名称回退。
3. 当前会话有匹配 Tab 时，复用 `agentTabTitle` 与工作区布局取得手动名称、共享会话标题，缺失时采用终端显示名/最近 prompt；尚未加载布局时先展示现有会话标题及 Tab 显示名。历史身份不能借用已切换会话的 Tab 标题；仅使用该历史身份的覆盖标题、prompt，最终显示“未命名会话”。不新增持久化字段。
4. 顶部项目路径使用辅助字号，Tab 标题使用主字号及更高对比度；Provider 和状态图标与标题同排。时间、摘要在标题后，状态选择器与历史入口收入卡片底部。选中背景覆盖整张卡片；删除按钮不覆盖正文，不触发导航。
5. 搜索包含根项目、当前项目、实际显示标题及原有字段。根项目或当前项目命中时较早记录同步显示；仅标题命中时不扩大较早记录。名称更新后展示与搜索立即一致。
6. 320/390/430px、桌面窄侧栏、浅深色下无横向溢出；长中英文名称、无空格字符串、文字放大可换行。移动端搜索、清空、分组、状态选择、删除、较早记录热区至少 44px。卡片导航支持键盘，当前项提供语义。
7. 不改变接口、会话存储、运行态推导、导航失败及保存失败反馈；执行相关回归测试、完整 TypeScript、改动文件 ESLint 和浏览器布局检查，真机限制单独记录。
