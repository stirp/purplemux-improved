# AI 会话文件通过网页访问

## 用户原始需求

现在会话过程中，codex 和 claude 会产生一些文件，这些文件访问的时候是通过打开编辑器的方式，比如 vscode。我希望手机端可以通过网页链接的形式用浏览器直接打开，因为手机没有可用的编辑器。

## 范围和覆盖关系

- 为 Claude、Codex 共用的 AI 回复和计划 Markdown 文件链接增加同源 HTTP 访问；手机设备或窄屏直接在新页打开，桌面无可用编辑器时也使用网页。桌面已有可用编辑器的点击行为保留。
- 替代编辑器跳转基线中上述入口只能依赖编辑器、且不新增文件读取 API 的约束；目录打开、差异编辑器入口及普通 HTTP 链接不变。代码块复制行为不变。
- 继续复用路径解析：支持绝对路径、相对会话 cwd 的路径、file URI、编码字符与行列后缀；文件链接无需 AI 重新生成。未提供 cwd 的相对路径不作为文件读取请求。
- 链接为可复制的普通网页 URL，无内嵌凭据；服务仍需对手机可达，访问者必须已有有效登录或 CLI 认证。不提供匿名公网分享、文件编辑、自动目录扫描或终端裸路径识别。

## 文件访问约定

- `GET /api/session-files/<逐段编码的绝对路径>` 读取文件。`?view=1` 为文本提供适合手机的只读页面和行号定位；不带参数时返回原文件，供 HTML 相对资源使用。其他格式的 view 参数不改变内容。
- 文本（包括 Markdown、代码、JSON）以转义后的源文显示；HTML、图片和 PDF 使用浏览器预览；未知类型以附件下载。文本预览上限 2 MiB，超限明确报错；原文件流式传输。
- HTML/SVG 使用 CSP sandbox 静态预览：允许同源资源携带登录 Cookie 加载，但禁用全部脚本、网络 API、表单、嵌套页面及外部资源；样式、图片和字体限于本文件接口。需要 JavaScript、外部 CDN 或网络请求的 HTML 不在完整运行保证范围。浏览器实测证明 opaque-origin sandbox 会使相对资源丢失 SameSite Cookie，因此使用 allow-same-origin 且不授予 allow-scripts。
- 仅允许服务器持久化工作区目录和系统临时目录内的普通文件；对允许根目录及目标执行 realpath，阻止编码穿越、符号链接越界、目录和设备文件。临时文件删除后链接失效。
- 路径边界修正：工作区根目录为符号链接时，链接路径及其真实路径都应可访问。打开之后、读取任何字节之前，必须针对实际文件描述符核验范围；父目录在校验与打开之间被替换、甚至在打开后恢复，都不得导致范围外文件内容返回。核验失败必须关闭描述符。
- 安全核验支持 Linux 与 macOS：Linux 读取 `/proc/self/fd` 的内核描述符路径；macOS 通过原生 `fcntl(F_GETPATH)` 查询同一个已打开描述符。平台适配只返回内核路径，不再次解析可变的文件名。调用失败、原生库不可用或平台不支持时返回 503 并关闭描述符，不回退到先检查路径再读取的方式。
- macOS 原生调用使用服务端依赖 Koffi；仅 macOS 路径按需加载。Web 安装包与 Electron standalone 打包必须包含原生依赖，不能要求用户另装 Python 或在首次访问时编译代码。Apple Silicon 和 Intel 均纳入测试入口；无 macOS 环境时必须区分本地模拟检查与实际 macOS 验证。
- 平台分支必须在运行时判断，Linux 上构建的 npm/standalone 服务端产物仍须保留 macOS 实现，不允许由构建机平台常量折叠掉其他受支持平台。
- 接口自身认证并显式纳入 proxy，覆盖图片扩展名；所有响应 no-store、nosniff、no-referrer。未登录 401、非法参数 400、越界或无权限 403、不存在或非普通文件 404、不支持的方法 405、预览过大 413、读取失败 500、安全描述符核验不可用 503；流传输失败关闭连接。

## 验收标准

| 编号 | 验收条件 | 验证方式 |
| --- | --- | --- |
| FW-01 | 手机/窄屏的回复和计划文件链接为 HTTP 地址；桌面编辑器与普通网页链接回归通过 | 组件测试、浏览器检查 |
| FW-02 | 中文、空格、特殊字符、相对路径、file URI、行列后缀解析正确 | 单元测试 |
| FW-03 | 文本安全且可读，HTML 和相对资源、图片、PDF 返回正确类型，未知格式下载 | 接口测试、浏览器检查 |
| FW-04 | 认证、编码穿越、符号链接、路径前缀碰撞、非文件及丢失文件正确处理；HTML 脚本不能执行 | 接口/文件系统测试、浏览器检查 |
| FW-05 | 相关测试、完整 TypeScript、改动文件 ESLint 和构建通过，实际限制记录在验证证据 | 命令验证 |
| FW-06 | 符号链接工作区的链接路径与真实路径均可读取；父目录替换及替换后恢复的竞态均拒绝，拒绝时关闭文件描述符 | 可控竞态的真实文件系统回归测试 |
| FW-07 | macOS 使用 F_GETPATH，Linux 行为保留；原生失败安全拒绝，Web/Electron 打包保留运行所需依赖 | 平台适配测试、原生集成测试、构建产物检查 |
