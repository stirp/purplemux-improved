# 顶部空间优化与移动设置全屏

## 用户原始需求

“web上单独占据的这一行有点奢侈了, 看看能否合并到下一行. 移动端这一行可能无法移动,但是最左侧的品牌名称其实可以不需要, 因为点击设置的时候会显示. 设置的时候没有占满移动端全屏, 我认为可以调整为全屏, 更大空间”。截图标示桌面 CPU/内存、编辑器、分屏和 Git 操作栏。

## 范围与覆盖关系

- 替代资源监控规格的桌面独立顶栏位置：Web 单分屏且 Git 侧栏关闭、内容区空间充足时，资源与操作区并入标签栏右端，不再额外占用 48px。依据内容区实际宽度和工具栏所需宽度判断，为标签滚动区、滚动箭头及新建入口合计保留至少 200px；空间不足或尚未测量时使用独立工具栏。侧栏拖动、窗口缩放及工具内容宽度变化后重新判断，空间恢复时自动合并。标签可横向滚动，新建及工具入口保持可达。
- 多分屏或 Git 侧栏打开时保留公共操作栏，避免最窄 200/320px 面板容纳全部操作；Electron 保留原窗口拖动区域。操作仍针对当前焦点分屏，不改变分屏、Git、编辑器行为。
- 替代移动顶栏品牌展示约定：移除 AppLogo 和品牌分隔符，包括无工作区状态。保留 48px 顶栏、菜单、工作区名称及编辑入口、资源监控与退出；不修改导航抽屉内的品牌。
- 设置仅调整布局：宽度小于 768px 时覆盖可用视口，显式取消居中定位、圆角和外部留白；处理安全区及软键盘。标题、关闭和横向分类导航固定，正文独立滚动。桌面维持居中弹窗，在矮屏下限制高度并允许内容滚动。
- 沿用配置存储、失败反馈、资源采样、本地化、浅深色及区域字体设置；无新增 API、依赖、配置键或数据迁移。

## 验收标准

1. 空间充足的 Web 单分屏中，标签、CPU/内存及操作处于同一行，省去独立 48px；长标签、多标签及 40px 区域字号可滚动且不裁切文字。800px 桌面窗口、400/480px 侧栏、资源监控和编辑器入口启用时自动回退独立工具栏，标签列表宽度大于零、新建按钮不被遮挡；扩大内容区后恢复合并，临界宽度不反复切换。资源开关及 Git 状态宽度变化也须重新判断。
2. 资源详情、编辑器、分屏、Git 切换及标签新建可用；进入分屏/Git 后公共栏可达，恢复单分屏且关闭 Git 后重新合并。Electron 拖动及按钮语义保留。
3. 320/390/430px 移动顶栏无品牌及分隔符，长工作区名省略，菜单、资源、退出保留至少 44px 热区。
4. 移动设置在 320/390/430px 和 740×360 横屏无外部留白、无横向页面溢出，关闭按钮及分类入口至少 44px；正文能滚动至末尾，Escape/关闭可用，软键盘可用视口与安全区被考虑。
5. 桌面设置保持居中，浅深色及放大文字可用。相关单测、完整 TypeScript、改动文件 ESLint 及浏览器检查记录实际结果与限制。
