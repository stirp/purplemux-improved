# 终端按键长按拖动排序

## 原始需求

“优化终端按钮排序优化，使用长按拖动方案就行”，截图为终端按键设置弹窗。

## 范围与行为

- 替代按键设置中的上下箭头按钮：每行右侧提供拖动手柄。触摸手柄静止长按 350ms 后纵向拖动排序；长按前移动超过 8px 取消激活，保留原生列表滚动。桌面鼠标移动 5px 后开始拖动。
- 手柄支持键盘空格开始/放下、上下方向键移动、Escape 取消；取消拖动不关闭弹窗、不改变草稿顺序。拖动时提供源条目和相邻条目移动反馈，靠近滚动边缘自动滚动。
- 勾选区域保留显示/隐藏切换，不启动拖动；隐藏条目仍可排序。拖动中禁止勾选、保存和关闭，避免中途提交或卸载；结束后恢复操作。
- 放下仅更新草稿。取消设置丢弃草稿，保存成功才更新按键栏；失败保留排序和勾选草稿供重试。读取失败和保存中禁用排序。
- 所有语言的设置说明同步更新为长按拖动，手柄提供本地化名称；桌面与移动端复用同一组件。
- 沿用已有 API、有序 ID/visible 数组、默认值、共享配置、刷新与重连同步，不新增依赖或持久字段，不调整终端输入及自定义命令排序。

## 验收标准

1. 上下箭头替换为拖动手柄；触摸长按及鼠标均能跨多行上下排序，原位放下和取消不改顺序，不发送终端输入。
2. 短按不排序；长按前滑动可滚动，触摸取消后可再次操作；勾选不误触拖动。窄屏列表和底部操作区可访问。
3. 键盘可排序；Escape 仅取消当前拖动，之后可正常关闭弹窗。
4. 保存、取消、保存失败重试、隐藏条目、加载失败及保存中禁用符合上述约定。
5. 相关组件/API 测试、完整 TypeScript、改动文件 ESLint 通过，执行浏览器验证或构建，如实记录实机限制。
