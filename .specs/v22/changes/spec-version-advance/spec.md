# 规格版本推进至 v22

## 用户需求与范围

用户在需求文档隔离规范调整后，要求 specs 版本继续前进。本次将新增需求入口由 v21 推进到 v22。
仅推进规格版本，不涉及 npm 包版本、发布或历史规格迁移。

## 行为约定

- 新需求写入 `.specs/v22/changes/<requirement-id>/`，各自维护规格、任务与实施/验证记录。
- 替代 v21 发布元数据规格中“后续需求归入 v21”及 AGENTS 当前入口指向 v21 的条款；原包版本与发布行为约定不在本次变更范围。
- 沿用按需求隔离规则，v22 不创建需要每个需求更新的版本 PRD、任务总表或集中索引。
- v21 及更早版本的需求、基线与证据保留；已有需求的后续修正继续维护所属版本的专属文档，独立新需求进入 v22 并引用相关基线。
- AGENTS 的新增需求路径和搜索示例统一指向 v22；v21 历史入口说明新版本位置，不向历史任务正文追加本次进度。

## 验收标准

1. AGENTS 的当前新增需求入口和发现命令指向 v22，命令可发现本需求规格与任务。
2. v22 使用独立需求目录，不存在需要逐需求维护的版本 PRD 或任务总表。
3. v21 历史需求索引、任务正文及已有需求文件不被迁移或改写；新增规格的基线引用可解析。
4. 文档链接、差异格式检查通过，包文件未发生本次变更。

见[任务](./task.md)和[实施与验证记录](./result.md)。
