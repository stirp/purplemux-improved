# 实施记录

规格：[新建 Tab 会话选择器](../spec.md)。本需求先补规格，再实现。

- `new-tab-picker.tsx` 统一桌面 Popover 和移动 Dialog 的应用入口、搜索、会话列表、安装检查、恢复中禁用及错误重试。移动端三个应用入口同行显示；保留桌面新建快捷键与方向键导航。
- `use-new-tab-sessions.ts` 按工作区目录、已打开 Tab 目录和回收记录目录收集数据；仅在选择器打开时挂载。使用 SWR 隔离项目缓存，重新打开时刷新。
- `new-tab-sessions.ts` 单次读取每个目录的 Claude 全量列表、原生 Codex 列表，复用 `collectWorkSessions` 合并持久索引与历史，按身份去重并应用标题/删除标记。部分来源失败时保留其他来源和回收记录。
- `/api/timeline/sessions` 支持仅传 cwd；有明确目录时无需存活 tmux。只传 tmux 的旧调用保留不存在时的 404；新增 `all=true` 返回全部可见项，旧调用的隐藏过滤和分页语义不变。
- 复用 `navigateToTabOrCreate`，增加可选发起 pane，已有会话仍优先复用；恢复 Tab 同样检查服务端返回 cwd 后才进入启动状态。同步 `docs/STATUS.md`。
- 新建回调返回创建结果，移动回调兼容共享选择器传入的完整启动命令；失败时保持选择器可重试。

KISS/DRY：桌面与移动共享交互和数据逻辑，复用已有恢复、配置、安装检查与工作流身份模型；不新增依赖、配置格式或恢复协议。旧 agent-sessions Tab 和全局 Sessions 保持可用。

## 评审修正（2026-10-29）

1. 会话合并发现其他工作区归属时，从原生候选 Map 删除相同 provider + ID；复用原有归属合并优先级，避免共享目录将其他工作区会话重新标为当前工作区。
2. 新增 `use-new-tab-action-store.ts`，通过同步原子占用和 `finally` 释放实现按工作区互斥；桌面/移动及多 pane 共用。实例卸载后继续保留进行中操作，完成时不执行旧实例的关闭回调。
3. 移除选择器的逐页读取循环，以一次全量请求消除后续页失败丢弃前页数据的路径；仍按目录/provider 独立处理失败。
4. 全量模式复用现有接口已经获得的完整列表，避免每页重复执行全目录扫描。保留旧接口分页行为，不增加快照缓存、缓存失效协议或新依赖。

本轮先更新规格，再修复代码。KISS：用现有完整扫描结果直接响应；DRY/SRP：共享互斥状态只负责占用和释放，列表合并、网络读取与界面生命周期仍分别处理。
