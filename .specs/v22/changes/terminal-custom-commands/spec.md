# 终端自定义快捷命令

## 原始需求

现有 terminal 界面的快捷操作太简单了，我希望允许用户自己增加自定义命令，并且可以自己设定名称。

用户补充确认：点击自定义命令后，直接发送命令并回车执行。

## 范围与行为

- 在桌面、移动端的普通 Terminal 界面增加自定义命令栏，独立于虚拟按键栏显示设置；保留原有固定按键及聊天快捷提示行为。
- 命令栏展示用户设定的名称，悬停可查看命令内容；提供管理入口和空状态新增入口。
- 管理弹窗支持新增、编辑名称和命令、删除（明确点击确认后删除）。取消编辑不保存。
- 名称去除首尾空白后须为 1–40 字符；命令保留原始空白，须有非空内容且不超过 4000 字符。允许多行，拒绝换行及制表符之外的控制字符。最多保存 50 条，名称可重复，以稳定 ID 标识。
- 命令控制字符校验覆盖 Unicode `Cc`：C0（U+0000–U+001F）、DEL（U+007F）及 C1（U+0080–U+009F），仅放行 TAB（U+0009）、LF（U+000A）、CR（U+000D）。客户端与新增/编辑 API 使用相同规则，普通 Unicode 文本保持原样。
- 点击发送命令到该栏所属的当前终端，换行归一化为 CR，末尾补一个回车；不清空终端已有输入，不启动独立 shell，不切换目录。界面明确说明点击会立即发送并回车，先确认终端当前输入状态。
- 桌面和移动端均复用网页输入通道：向上滚动进入 tmux copy-mode 后，先退出复制模式，再将命令写入当前终端，避免命令被当作复制模式按键消费；终端原生按键仍沿用原输入通道。
- 断线时禁用执行，不排队或重连补发；保存、刷新、重连不会自动执行。
- 配置为当前 Purplemux 实例共享，写入 `~/.purplemux/workspaces.json` 的可选 `terminalCommands` 字段；复用工作区文件锁、原子写入及广播。旧文件缺少字段时默认为空，不改变其他字段。
- 新增、修改、删除按单条命令提交，锁内读改写，避免不同命令的并发修改互相覆盖。修改已删除 ID 返回 404。
- 保存成功才更新列表并退出编辑；失败保留输入并展示错误。读取失败显示重试，不能误当成空列表。
- 桌面和移动共用组件及 API；同页通过 SWR 共享，跨客户端在工作区广播、重新连接、窗口聚焦时刷新。

## 验收标准

1. 无旧配置时可新增中文名称和 shell 命令，保存后按钮显示该名称；刷新或重读文件后仍存在。
2. 编辑名称或内容立即反映到列表；取消不改变数据；删除须显式确认，删除后不再出现。
3. 空白名称/命令、超限、非法控制字符被客户端与 API 拒绝；覆盖全部 C0/DEL/C1 字符和 TAB/LF/CR 例外，U+009B 粘贴不能保存，普通 Unicode 文本可保存；请求异常不覆盖已有数据。
4. 点击仅发送命令到当前终端，按约定归一化换行并回车；桌面和移动端在 tmux copy-mode 下点击时，先退出复制模式再执行；断线禁用，重连不自动发送。
5. 保存失败保留草稿并反馈；读取失败支持重试。
6. 桌面默认按键栏隐藏时仍可管理和执行命令；移动端窄屏可横向滚动列表，弹窗可滚动且输入与按钮可访问。
7. 并发新增不同命令均保留；其他工作区字段和现有固定按键不受影响。
