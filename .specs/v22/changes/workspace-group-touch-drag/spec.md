# 移动端分组长按拖动修复

## 用户原始需求

“现在至少移动端的分组不能通过长按触摸的方式来拖动，修复这个问题”

## 范围与行为

- 补齐移动导航分组标题的触摸及鼠标排序；复用现有触摸手势、导航拖拽及分组持久化接口。
- 非搜索状态，在分组名称、箭头或计数区域静止长按 350ms 启动拖拽，移动到另一分组标题上半部或下半部，在释放时插入到目标前或后。
- 拖动期间显示源标题透明度和目标插入线；释放不误触折叠。短按仍折叠/展开，长按前滑动仍允许原生滚动。
- 分组只与分组排序，不能与工作区或 Tab 混排；支持空组、折叠组，并保留成员关系和组内顺序。
- 更多按钮及菜单操作不启动拖动；取消、多指及卸载不提交排序；搜索期间禁拖，清空后恢复。
- 沿用保存失败提示和刷新恢复、既有同步逻辑；不修改配置结构、桌面鼠标行为或工作区长按菜单时序。

## 验收标准

| 编号 | 条件 |
| --- | --- |
| GT-01 | 实际移动导航组件长按并上下拖动分组后调用既有保存接口，空组与折叠组可排序，成员关系及组内顺序保留 |
| GT-02 | 短按折叠、普通滚动、更多菜单可用；拖动释放不误折叠；取消、多指、卸载及非法目标不保存 |
| GT-03 | 搜索期间不启动分组拖动，清空恢复；工作区、Tab 及桌面拖动回归通过 |
| GT-04 | 相关测试、完整 TypeScript、改动文件 ESLint 通过；构建或浏览器验证记录实际结果，真机验证独立标明 |
