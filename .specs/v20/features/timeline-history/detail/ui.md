# 按轮加载历史与长消息展开：界面与交互

## 入口与展示

时间线提供加载更早对话的入口；长用户消息可以展开和收起。

## Chat 内容宽度（2026-10-12）

- `timeline-view.tsx` 的消息区与加载骨架、`web-input-bar.tsx` 的输入框与连接提示、`quick-prompt-bar.tsx`、`agent-status-line.tsx` 统一使用 `chat-content` 样式。
- 外层 `width: 85%`、`margin-inline: auto`，没有固定最大宽度；基准为所在面板，所有屏幕尺寸均使用相同比例。
- 保留各组件内部 padding；用户气泡最多占消息内部区域的 85%，与聊天外层宽度是两层独立约束。
- 调整窗口或分屏立即由 CSS 重排，不增加设置、请求或保存状态；统计和报告页面仍使用 `max-w-content`。

## 交互验收

- 加载多轮不重复、不遗漏轮次边界；大文件不一次全量加载。
- 长消息展开收起不改写原文。

## 异常与边界

- 分页边界按对话轮次，不等同于固定条目数。
- 必须区分 Codex 旧模式替换行为与按轮增量模式。
