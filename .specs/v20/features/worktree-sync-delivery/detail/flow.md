# Worktree 同步与 PR/MR 草稿交付：使用流程

## 基本流程

1. 从工作区交付入口选中工作树，加载目标和比较结果。按保存目标、创建基线顺序选择有效默认值；均无有效值时回退到该工作树当前本地分支。
2. 必要时显式 fetch，选择 merge/rebase，将目标分支同步到当前工作树。
3. 人工解决冲突后 continue，或 abort 恢复。
4. 确认推送预览提交，编辑草稿内容后创建或关联 PR/MR。

2026-09-29 增量：默认目标为自身时只展示比较结果，merge/rebase 不可用；用户可切换其他目标，刷新保持显式选择。打开弹窗不保存默认目标或自动执行 Git 写操作。无当前命名分支时不生成自身目标。

## 异常与约束

- 同步不修改目标分支；不执行 force push。
- 草稿目前只支持同远程仓库分支，不支持跨 fork 草稿。
- 远程失败显示未知或未确认；远程创建成功但本地关联保存失败时仍保留链接。

具体实现与测试入口见[规格](../spec.md)。
