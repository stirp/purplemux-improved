# AI 提交信息、PR/MR 文案与提交确认：使用流程

## 基本流程

1. 检查改动并取得文件清单及快照。
2. 生成或手动编辑提交信息。
3. 确认后复核快照并提交；变化时要求重新预览。
4. 交付时基于已提交差异生成草稿描述，再走独立 PR/MR 创建流程。

## 异常与约束

- 文案生成使用 Claude 无工具模式；模型返回内容须通过结构和长度校验。
- PR/MR 生成不纳入未提交内容；超出证据上限时标记截断，不编造测试结果。
- 快照过期、冲突、Git 操作中或索引锁冲突需阻止提交；提交完成后 hook 异常不得诱导重复提交。

具体实现与测试入口见[规格](../spec.md)。
