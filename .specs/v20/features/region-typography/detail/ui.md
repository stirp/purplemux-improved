# 区域字体界面与交互

## 入口和组件

设置对话框的“外观”页在自定义 CSS 编辑器之前展示区域字体面板。
编辑器独立封装在 `src/components/features/settings/region-typography-settings.tsx`。

| 区域 | 应用位置 |
| --- | --- |
| sidebar | 桌面侧边栏 sidebar.tsx |
| tabs | 桌面 tab-bar.tsx 和 pane-tab-bar.tsx |
| messages | timeline-view.tsx 的消息内容容器 |
| input | web-input-bar.tsx 的输入区域 |
| terminal | pane-container.tsx 和 mobile-surface-view.tsx 的终端组合点，包括 Agent 终端；不包含登录安装终端 |

DOM 组件用 `region-typography-*` 类消费 `:root` 中的 `--region-*-font-family/font-size/color` 变量；所有后代文本自动参与，无标签允许列表。终端由组合点生成 xterm props。

## 表单

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 字体名称 | 文本输入框 | 最多 200 字符，多个名称用逗号分隔，不加引号 |
| 字号 | 数字输入框 | 8–40 px，留空使用默认；界面步进为 1，接口允许范围内有限数值 |
| 字色 | 颜色选择器和文本输入框 | #RRGGBB，留空使用默认 |

每个区域展示含中英文和数字的预览。预览只作用于样例，点击应用才修改实际区域。
字段留空意味着移除对应覆盖；没有配置颜色时选择器展示占位颜色，须选色才形成配置。

## 操作和反馈

- 恢复默认：清除对应区域草稿中的覆盖，点击应用后保存。
- 全部恢复默认：将草稿置为空对象，点击应用后保存。
- 放弃修改：返回已保存配置，不发起 PATCH。
- 应用：存在有效改动时可用；保存期间禁用整个区域编辑面板。
- 校验失败：展示错误说明并禁用应用；预览不使用非法样式。
- 保存失败：显示错误提示，保留草稿供重试。

简体中文和繁体中文提供对应文案，其他现有语言资源提供英语文案。
任意字体是否可显示取决于查看设备；缺失时使用浏览器及终端回退字体。

## Review 修复约定

无效颜色文本展示错误标识，暂停颜色选择器，用户先修正或清空后再选色。
保存失败提示保留服务端错误详情。键顺序变化不使等价草稿变脏。
字体名称或字号覆盖时标签栏使用自适应行高与内容高度，移除固定小行盒限制。

## 组件布局约定（2026-10-05）

普通标签栏 min-height 为 30 px，分栏标签栏为 36 px，垂直内边距由各组件维护。
区域注入样式只生成变量，不修改高度；错误和加载分支与正常分支使用相同区域类。
未设置的字段回到原有 Tailwind 规则，设置字号时行高为 normal；自定义 CSS 可覆盖区域规则及变量。
