# Worktree 创建、接入与安全删除：接口与数据

## 接口或内部通道

- GET /api/workspace/worktree：查询创建所需的仓库与分支；POST 创建工作树。
- GET /api/workspace/worktrees：总览；POST 接入；DELETE 删除。
- 管理面板查看时每 10 秒刷新；上游进度使用本地 Git 引用。

## 数据与执行边界

- 主工作树、锁定或状态未知的目录不得直接删除；活动会话与不安全改动需阻止删除。
- 移除子工作区与删除磁盘 Worktree 是不同操作。默认不 fetch、不删除分支。

此处说明本功能相关契约；完整字段、校验和错误分支以[规格所列源码](../spec.md)为准，不另造接口。
