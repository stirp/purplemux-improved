# 移动端工作区操作、Tab 改名与触摸拖拽：使用流程

## 基本流程

1. 打开移动导航，定位工作区及其子项。
2. 长按开始拖动并调整顺序，或打开上下文菜单操作。
3. 改名 Tab、进入 Worktree 管理或交付，再返回当前会话。

## 空工作区选择（2026-10-12）

1. 点击目标工作区行，调用共享项目选择处理器并展开或收起目录。
2. 切换项目时清理旧布局和元数据，加载目标布局；其他页面返回工作区页面。
3. 关闭导航抽屉，在空 pane 的“新建 Tab”入口创建标签；请求使用当前工作区和 pane。
4. 布局加载失败沿用已有切换回退和提示，不自动创建 Tab。

## 异常与约束

- 拖拽不能误开菜单，菜单不能吞掉正常点击。
- 桌面鼠标交互与触摸设备行为必须同时保留。

具体实现与测试入口见[规格](../spec.md)。
