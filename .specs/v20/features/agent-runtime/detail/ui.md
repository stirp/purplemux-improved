# Agent 启动、环境配置与会话绑定恢复：界面与交互

## 入口与展示

设置页分别展示 Claude/Codex 环境变量；Agent 面板展示连接和就绪状态，输入栏依据状态开放交互。

## 交互验收

- 嵌套 shell 下能识别 Claude；初始 unknown 状态正确收敛。
- Codex 新进程获得环境变量，review 期间保留根会话绑定。

## 异常与边界

- 环境变量只作用于新启动进程，不追改运行中的进程环境。
- review 子会话与根会话身份需区分，不能因子会话 hook 切换面板绑定。

## 独立配置编辑器

设置的 Agent 页纵向展示 Claude、Codex 两个编辑器，复用组件并使用各自字段和 DOM id。每行 NAME=value，允许带前导空白的可选 export 前缀；空配置继承进程环境。每个编辑器独立维护草稿、校验错误和保存状态。保存期间禁用输入和按钮，成功显示 toast，失败保留草稿并允许重试。使用 label、aria-describedby、aria-invalid 和 alert；窄屏保持单列。
