# Claude 启动信任提示恢复

2026-10-10：用户截图显示 Claude 停在目录信任确认，聊天区却显示空时间线，无法在聊天区选择。

## 范围与验收

1. 桌面及移动端在 Claude 启动信任确认可见时展示已有信任卡片，不依赖 CLI 恰好处于 inactive；保留终端入口。
2. 兼容有编号的旧提示和截图中的无编号提示；同意与退出均明确发送用户所选答案，不自动信任目录。
3. 从当前终端已解析的可见缓冲读取；启用、切换标签、重连输出时重新检测，旧标签卡片不能回答新标签。
4. 提示消失后恢复原面板；提交前重新检查当前提示，过期卡片不发送输入。
5. 回归 Codex 信任提示；相关测试、完整 TypeScript、改动文件 ESLint、构建及浏览器验收分别记录实际结果。

## Review 补充（2026-10-10）

- 导航键与 Enter 必须分两次写入，间隔沿用终端命令的 80ms；待提交期间切换标签/会话、禁用检测或卸载时取消 Enter。
- 选项复用 permission-prompt 的解析规则，兼容软换行和窄屏编号；答案以选项前缀识别，括号说明不能改变答案。
- 路径、选项、光标必须属于最近同一提示块。编号菜单及导航菜单使用判别联合表达；无编号菜单光标无法识别时不得回退数字输入。
- 提交前校验失败保留卡片及可重试按钮，移动端提供查看终端入口。
- scopeKey 同时包含标签和代理会话 ID；测试不依赖 debounce 的固定值，并验证分次写入时序。
