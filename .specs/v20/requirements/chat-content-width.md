# Chat 内容区比例宽度

- 日期：2026-10-12
- 关联规格：[timeline-history](../features/timeline-history/spec.md)

## 用户需求

大屏幕上聊天文本左右留白过多。Chat 内容区占所在面板宽度的 85%，不设固定最大宽度；用户通过窗口大小控制阅读宽度。

## 范围与验收

消息区、加载骨架、输入框及连接提示、快捷提示、Agent 状态栏共享居中的 85% 外层宽度，桌面、移动端和分屏均按各自面板计算。
保留各组件内部间距及用户气泡的现有比例限制，不新增设置或持久化字段。
具体验收编号见功能规格 CW-01 至 CW-03。
