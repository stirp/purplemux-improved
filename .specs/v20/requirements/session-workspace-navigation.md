# Sessions 导航同步侧边栏项目

2026-10-07：用户要求从 Sessions 管理进入历史会话时，侧边栏同步切换到所属项目，便于定位。

- 关联规格：[会话生命周期](../features/session-lifecycle/spec.md)。
- 进入已有 Tab、恢复历史会话或重建已删除工作区成功后，侧边栏切换至项目列表并高亮实际目标工作区。
- 展开目标所在分组；子工作区祖先沿用现有激活路径展开逻辑。
- 同项目导航也切换项目列表；隐藏覆盖会话的内嵌网页。
- Claude/Codex、桌面/移动端共用导航逻辑；移动端保留原有导航抽屉关闭行为。
- 缺少工作区路径、查询/创建失败时，不提前切换侧边栏。保留原有错误处理。
- 2026-10-08 复审修正：仅 Sessions 历史入口触发项目定位。toast、系统通知、web-push 深链、移动端 Tab 选择维持原导航行为。
- 分组展开为临时显示，不修改保存的折叠偏好，不发送分组 PATCH；离开目标项目或手动操作分组后取消临时展开。
- 进入前验证服务端布局中的 Tab；失败、失效 ID、未完成 hydrate 时不提前更新选择、侧边栏或 webview。已有代理 ID 可沿用历史恢复规则创建新 Tab。
- 复用桌面/移动端注册的项目选择处理器，保留元数据重置与上一工作区记账。不增加接口或配置字段，不强制打开已关闭的抽屉或侧边栏。

## 验收

1. 跨项目、同项目和从其他路由进入已有会话，目标工作区与 Tab 正确，项目列表显示目标选择。
2. 目标分组收起时展开；父子工作区沿激活路径可见。
3. 两类代理复用会话、创建新 Tab、重建工作区后，均显示实际所属项目。
4. 恢复查询/创建失败或缺少重建路径时，保持当前侧边栏状态。
5. 完整类型检查、改动文件 ESLint 和相关回归测试通过；未执行的浏览器/实机验证明确记录。
6. 非 Sessions 导航不切侧边栏标签、不关闭 webview、不改变折叠偏好；Sessions 失效 Tab 不产生部分定位状态。
7. 测试恢复各 store 的完整初始快照和模块状态，重建场景验证真实分组显示且保存的 collapsed 不变。
