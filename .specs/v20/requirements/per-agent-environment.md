# 按代理独立配置环境变量

- 日期：2026-09-29
- 状态：已实现，自动化验证通过；实机验收未执行
- 关联规格：[agent-runtime](../features/agent-runtime/spec.md)

## 原始需求

Codex 和 Claude 支持不同的环境变量设置，并按照项目 spec 开发。

## 行为与验收

1. 设置页分别展示 Claude、Codex 环境变量编辑器，独立保存、清空和显示错误；刷新后保留各自配置。
2. 保留 `codexEnvironment`，新增 `claudeEnvironment`，旧配置缺失字段按空对象处理，不复制另一代理的变量。
3. 新启动及恢复会话仅叠加对应代理配置；覆盖同名继承变量，保留其他继承变量，不修改父 shell 或运行中的会话。
4. 桌面、移动端、服务端启动和恢复入口行为一致。应用内部 AI 文本生成也按所选代理读取配置，调用方显式环境优先。
5. 每行 `NAME=value`，允许带前导空白的可选 `export ` 前缀；支持空值、等号和 shell 特殊字符，值保持字面量。拒绝非法名称、重复名称和 NUL。
6. 启动命令和日志不包含配置值。Claude 的共享 Node 启动包装器在执行时读取配置，通过 spawn 的 env 传递；Codex 保持已有 launcher。
7. 保存失败保留草稿与已保存配置，显示错误；保存期间禁用对应编辑器和按钮。

## 验证安排

覆盖 API 校验、store 隔离及失败、双编辑器渲染、Claude 启动/恢复环境合并与字面量、Codex 回归、AI 文本调用；执行 lint 和完整 TypeScript 检查，记录未执行的浏览器验收。

结果见[实施记录](../result/build-per-agent-environment.md)和[验证记录](../result/verify-per-agent-environment.md)。

## Review 补充验收

- 额外 shell、Node 包装器、非 exec 函数组合下，运行检测及 PID 文件绑定均能找到真实 Claude 进程；不绑定 pane 树以外的 PID。
- 登录 shell 初始化覆盖同名变量后，用户代理配置仍优先；覆盖 sh/bash/zsh/fish、引号、反斜杠、换行、空值与标准输入保留。

- Shell 转义必须可直接审阅。启动器代码和参数应在 sh/bash/zsh/fish 中原样还原；workspace/resume 值中的 $、反引号、命令替换、引号、反斜杠和换行不得作为 shell 语法执行。

## 配置健壮性与缓存

- Claude 启动器拒绝 null、数组或标量配置根节点，并输出可定位的 config.json 错误；读取上限为 4 MiB，超限不启动，且文件读取期间增长也不得突破上限。
- API 与 Claude 启动器复用同一环境校验函数；按显式 provider→字段映射保存环境，无变化（包括仅键顺序变化）跳过 PATCH。
- 代理文本调用首次读取并缓存配置；应用写入立即失效，外部修改/原子替换通过文件元数据监听约一秒内失效。监听不可用时回退实时读取。配置缓存跨自定义服务器与 Next 模块图共享，返回的环境副本不会修改缓存。
- 回归必须明确断言另一代理的专属键不存在，同时保留继承环境和调用方显式覆盖语义。


## 2026-09-30 边界验收

增加管道读取失败/空流/截断拒绝启动、120 秒确认超时、有界进程扫描、改名 Fish 能力探测、配置读写大小一致及无关目录事件不影响缓存的验收。

保留合法环境变量 `export=value`：只有独立的 `export ` 命令前缀才剥离，名称和值都不作为未转义 shell 代码。保留真实退出信号处理：kill -0 仅探测进程，不发送退出信号，不会产生子进程 exit 事件。
