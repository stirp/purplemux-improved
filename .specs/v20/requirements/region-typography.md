# 设置中的区域字体调整

- 日期：2026-10-03
- 状态：已实现，自动化检查通过；浏览器实机验收未执行
- 关联规格：[region-typography](../features/region-typography/spec.md)

## 用户需求

在设置里对现有组件的字体、字色、字号做调整，增加设置入口和能力。
后续开发按照项目 spec 执行，并在 AGENTS.md 中写明开发流程。

## 范围

设置 → 外观 → 区域字体，覆盖侧边栏、桌面标签栏、会话消息、消息输入框及终端（含 Agent 终端）。
每个区域独立覆盖字体、字号和字色，支持预览、应用、放弃修改及恢复默认。
复用服务端配置和现有同步连接，兼容没有区域配置的旧用户。

## 验收要求

验收编号和验证方式统一维护在[功能规格](../features/region-typography/spec.md)，避免多份清单漂移。

## 当前边界

- 使用查看设备已安装的字体，不提供字体文件上传或字体列表自动发现。
- 字号为 8–40 px；字色为六位十六进制颜色，使用固定颜色覆盖而非按主题分别配置。
- 区域配置为服务端共享配置，不提供每设备、每工作区或每个组件实例的独立设置。
- 终端覆盖默认前景色，保留 ANSI 彩色输出。
