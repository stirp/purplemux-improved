# Sessions 与 Workspace 工作状态管理

2026-10-13 用户需求：工作状态表达完整工作的阶段，允许人工修改；Sessions 分类可以折叠；Workspace 任务状态由关联 sessions 推导。

## 行为与验收

- 工作状态为未开始、进行中、审批中、已完成。运行时 busy/needs-input 等继续表示模型执行状态，不作为人工工作的完成判据。
- 人工状态按 provider + session ID 保存，无 session ID 时使用历史 ID 或 Tab ID；人工选择持续优先，允许恢复自动判断。
- 自动规则：执行或等待输入为进行中；一轮产生结果为审批中；未执行为未开始；已完成仅由人工确认。
- Sessions 每个分类显示会话数量，点击标题折叠或展开，桌面和移动端一致；偏好保存到服务器，刷新和重连恢复。
- Workspace 汇总本工作区关联会话（历史及当前 Agent Tab，去重）：有进行中则进行中，否则有审批中则审批中，否则有未开始或无会话则未开始，全部完成才已完成。不将子工作区或模型 Todo/Plan 当成本工作区任务。
- 保存失败提示，保留原状态；多客户端通过现有 workspace 同步更新。
- 旧数据无新增字段可正常读取；历史轮次不重复计数；关闭通知或 Tab 不代表整个工作完成。

## Review 修复约定（2026-10-13）

- 当前会话判断必须匹配 provider + session ID；Tab 被其他会话复用时，旧历史仍可导航。
- Tab 首次绑定原生 session ID 时，服务器原子迁移人工 fallback 状态并消费 fallback，记录已绑定身份；同 Tab 再次绑定另一会话不得继承旧状态。
- 同步 WebSocket 每次建立连接均补拉 Workspace 状态，包含人工状态和分类折叠，无需切换可见性或等待广播。
- 独立保存每个会话与 Workspace 的关联及最近一轮导航摘要；200 条轮次历史裁剪不裁剪会话索引。老数据从仍保留的历史和当前 Tab 回补，已经丢失的关联不推测。
- 显式删除历史会话时清除对应索引及人工状态，避免下次读取复活。保存并发、回补、身份迁移复用 Workspace 全局锁。

## 第二轮 Review 修复约定（2026-10-13）

- 删除在 Workspace 写锁内保存持久删除标记，回补、状态广播和客户端派生均排除该标记；迟到的历史快照、inactive Tab 和后续关闭 Tab 均不能复活会话。
- 回补在同一写锁内重新读取现有 hidden-sessions 标记，兼容旧数据和删除流程中途失败；不依靠历史快照读取时机推断删除顺序。
- 无轮次会话的索引保存独立导航目标：provider、原生 session ID、Workspace ID/名称/目录及 Tab ID；不伪造已完成轮次。
- 无轮次索引按原生身份恢复和判断当前会话，并提供同一历史删除入口。Tab 被复用或关闭后，不能导航到新会话，也不能误禁用旧会话。

## 第三轮 Review 修复约定（2026-10-13）

- 首次绑定的原生身份已删除或隐藏时，仍消费 Tab fallback 状态和索引并记录绑定，但不迁移状态到已删除身份；关闭 Tab 后不残留 fallback，同 Tab 的新会话不继承旧人工状态。
- 无历史轮次会话行使用实际 DOM 菜单触发器，桌面右键及移动端长按均可打开删除菜单；左键导航保持按原生身份判断。验证必须使用真实 SessionHistoryActions 和 ContextMenu。
