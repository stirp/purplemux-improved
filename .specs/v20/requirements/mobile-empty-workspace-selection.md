# 移动端空工作区选择

2026-10-12：用户反馈，移动端点击没有任何 Tab 的 Git 工作目录时，聊天区仍停留在旧项目，无法为目标项目新建 Tab。

## 行为与验收

- 点击移动导航中的工作区行时选中该项目，不依赖其是否存在 Tab；保留原有展开/收起行为与抽屉状态。
- 复用已有项目选择处理器，保留上一工作区记账、布局清理和元数据重置；从其他页面选择时返回工作区页面。
- 从 `/stats` 等页面选择其他项目且没有注册选择处理器时，须在切换项目及返回首页前同步清空全局旧布局；目标布局加载完成前不得展示或操作旧 pane。同一项目重复选择不清空布局。
- 空工作区加载后展示已有“新建 Tab”入口，创建请求归属所选工作区及其 pane。
- 有 Tab 的项目、子工作区和当前工作区的展开/收起仍可使用；点击 Tab 维持原导航行为。
- 不新增接口、配置或自动创建 Tab。
